快速开始

            

                
方式1: Docker (推荐)

                cd docker && docker-compose up -d
                
                
方式2: 本地开发

                cd frontend && npm install && npm run dev
                cd backend && npm install && npm run dev
                
                
方式3: 简化版 (当前)

                直接打开此HTML文件
